Hello from FastAPI App! 🚀

This is a standalone FastAPI application running within Airflow 3. Unlike external views, this app is accessed directly via its URL prefix.

🔗 API Endpoints

GET /fastapi-app/ Root API information
GET /fastapi-app/info Plugin details
POST /fastapi-app/api/message Send messages
GET /fastapi-app/docs Auto-generated API docs
